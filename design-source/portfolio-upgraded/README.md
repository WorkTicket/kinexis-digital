## Reference study

The visual study included FireFly Effects, Steve's Modern Roofing, Volt Vikings, Concrete Fixers, Haro Electric, Jeff Likes Clean, Proline Garage Doors, Candy Wraps, Junk Bros, Martz, and TAGG. The transferable principles were a coherent visual world for each business, subject-led photography, strong type hierarchy, trade-specific edges/materials, useful service presentation, and varied page pacing. Some references do use owner cutouts; zero models in our heroes is the requested creative direction rather than a claim that none of their sites use them.
