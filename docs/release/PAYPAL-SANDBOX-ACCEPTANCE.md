# PayPal sandbox acceptance

**Status: PARTIAL — PayPal provider sandbox API check passed; application checkout/D1/webhook lifecycle acceptance remains open.**

On 2026-11-17, after explicit owner authorization, `npm run check:paypal-sandbox` ran against the exact PayPal sandbox API using credentials from the supplied ignored local env file. OAuth succeeded; the test created and read an unpaid sandbox order, confirmed capture of that unapproved order was refused, and completed a sandbox-only $1 card capture. No live customer charge or production configuration change occurred. The sandbox test exposed and the agent fixed an undefined `isSandbox` guard in the script, replacing it with an explicit sandbox API URL comparison. `npm run check:invoice-security` has passed mocked order/capture integrity, association, ledger, route, import, reconciliation, and webhook fixtures; this does not prove the end-to-end application lifecycle on preview.

**Safety correction:** the prior sandbox script used hard-coded production callbacks and could make an OAuth request to the default live API before refusing live order creation. The local test script now refuses all provider requests unless the API base is exactly the PayPal sandbox endpoint and both callbacks use the isolated preview host with the expected paths. Local URL contract assertions reject the production host, non-HTTPS callbacks, and wrong paths. This is test-tooling protection, not sandbox acceptance.

**Remaining acceptance:** verify the preview Worker is sandbox-only and its callbacks/webhook registration and D1 binding are isolated; exercise the application checkout/capture/webhook lifecycle on preview. Cover invoice association and persistence, cancellation/failure, duplicate/replay, amount/currency/merchant/invoice mismatch, invalid signature, persistence failure and retry; verify ledger state after each. The current provider API script alone does not establish these. Credentials remain only in ignored `.env.local`; do not expose or commit them. No live charges or production configuration changes.
